Loads color settings from a configuration file. Each line in the configuration file defines one color. On each line there are 9 integers separated with spaces indicating color settings (MIN_B MAX_B MIN_G MAX_G MIN_R MAX_R CEN_B CEN_G CEN_R), where CEN is the centroid location in RGB space (0 to 255).

Compiles the OpenCL program that looks at the pixels in an image and assigns each of them to one of the colors defined in the configuration file (0 indicates no match, positive integers indicate the line number of the color in the configuration file.

void gg::BlobDetector::findBlobs ( )

Connect same color pixels into blobs.

Uses the buffer returned by OpenCL to connect pixels into blobs.

On every row of the image, sequential pixels that have been assigned to the same color are saved with their color, starting index and end index. After a sequence has been found, it is checked if there is a sequence on the previous row with the same color and whether at least 2 pixels are on shared columns. If not, then a new blob instance is created which contains only the new sequence, otherwise the sequence is appended to the blob that contains the previous one.

After all of the rows of the image have been processed and the potential blobs have been constructed, the blob detector saves only those blobs in memory that contain more than a single sequence. This means that the blobs must span at least two rows.

cv::Mat gg::BlobDetector::processImage ( const cv::Mat &  mat)

Process OpenCV material.

Using OpenCL, pixels are assigned to clusters by first looking at the MIN-MAX ranges of the configured colors and checking if the pixel is within the range. If the pixel is in only one of the ranges, it is assigned to that color. Otherwise, the pixel is assigned to the color whose centroid is the closest. The results are saved to a buffer that are used by the blob detector.
